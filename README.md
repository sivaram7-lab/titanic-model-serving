# Titanic ML Model Serving with FastAPI

Dataset: https://www.kaggle.com/competitions/titanic/data (train.csv)

## Description
Trains a Random Forest pipeline on Titanic data and demonstrates online,
batch and streaming inference, plus a FastAPI REST API.

## Run steps
1. pip install -r requirements.txt
2. python train.py
3. python online.py / batch.py / stream.py
4. uvicorn app:app --reload
5. python client.py
